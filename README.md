# Shiksha Line

A transit-map style guide to free and low-cost courses in India, for anyone who can't afford college fees.

- **Route map** of six learning tracks: Code & Tech, Trades & Skills, Degrees & School, Exams & Study, Business & Money, Digital & English
- **Journey planner** that suggests three courses based on where you are starting and where you want to go
- **45 courses** (29 government, 16 private) with search and filters for fare, language, offline access and certificates
- **Save** courses to a list kept in your browser
- **Rider tips** on avoiding fee scams, financial aid, offline options, paid apprenticeships and scholarships

It is a single static file (`index.html`) with no build step. Open it in a browser, or host it with GitHub Pages.

Fees, stipends and eligibility change often. Always confirm on the official site before you enrol.
